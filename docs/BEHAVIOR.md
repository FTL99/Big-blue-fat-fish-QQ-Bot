# 默认人格修改与实际表现

## 当前交付的是哪个版本

发布整理时从实际启用的 persona 读取 V2；UTF-8 文本 SHA256 为 1c154b66c7d52e70d3cf421188b82bd1b8d6a8ca38237c85a4888199e4a3d033。persona/whale-v2.md 保留其实际正文，未用实验候选替换。文件换行规范可能影响文件字节哈希；生产文本原始哈希记录在 provenance/code-origin.json。

这与原部署包的“大肥鱼”默认卡不同。原卡已经要求像群友、理解引用、不编事实，并非完全没有上下文规则；但同时强烈限制 1—10 字，允许已读乱回、装傻及优先顶嘴，可能与完整表达和问题理解冲突。V2 减弱这类硬性表达约束，保留傲娇、好胜、机智、坏心眼与熟人互损，明确人格不能替代理解。

当前卡仍有“智商降低/看你顺眼”等示例，不能将与示例相似的输出当成独立幽默泛化的证据。先前 V2.1 的机制实验、人工盲评材料和候选提示不等于当前线上默认版本，本包没有以相同名字混入这些实验。

## 想改成什么样

- 当前消息决定需要回应什么，历史用于理解指代、说话者与讨论背景；“为啥”“怎么看”先找直接承接，不能仅凭关键词回旧话题。
- 保留主动参与，但有自然参与机会才回复，不靠每句互损刷存在感。
- 日常短句，必要时把观点说完整；不强制每轮嘴硬，也不强迫每轮认真回答。
- 记忆有来源和范围；玩笑不是自动成立的事实，工具未写入成功不声称永久记住。
- 图片可直接表达情绪，斗图可连续接招并收尾；对方转认真问题时停止斗图。

读空气决定是否参与，回复规则决定如何组织消息，人格影响表达；三层都可能影响观感。因此不把所有改进都归因于换了一张卡。

## 用户实际反馈与修复证据

实际使用中出现过：短追问承接错误、哑铃体感讨论被压成数学比较、幽默复读示例、称呼更正延迟、分开发送 @ 和表情未续接、背景启动错误。这些反馈说明当时版本确有可见问题，单张截图不能证明唯一根因，也不能证明修复后的长期表现。

| 已有检查 | 观察 | 证据能支持什么 |
|---|---|---|
| 轻松场景主动配图 | 候选群聊 9/10、私聊 4/5；原群聊规则对照 1/10 | 当轮回复格式能影响选图；不同阶段小样本，不是未来稳定发图概率 |
| 称呼更正 | 6 个虚构模型场景均采用当前称呼；真实框架存储写入后由新进程读回 | 指定句式和所测上下文能够保存、注入更正；不代表所有复杂指代都正确 |
| 连续斗图 | 群聊与管理员私聊各测一次三轮，下一轮接入实际生成的上一轮回复 | 连续状态与模型接续有可行性；不是长期真实群送达验收 |
| 认真话题退出 | 两次模型场景回答字典取值问题且不配图；离线路由测实际概率/判断入口 | 所测认真问题可退出斗图并获得回复机会；自然语言检测仍是有限规则 |
| 联网工具 | 8 次模型请求；真实搜索、网页读取探测及模拟失败检查 | 工具链在指定模型/账号下工作，失败可显式处理；不保证陌生梗都有可查答案 |
| 长期记忆与自身形象 | 本地向量/SQLite/FAISS 隔离检索；参考图交叉识别及无关图负例通过 | 指定流程可工作；不证明任何换装、遮挡图片都能认出，也不证明长期记忆永不出错 |

这些结果来自 2026-10 的不同迭代，原始材料留在本地，未把包含请求/潜在个人信息的测试目录打包。评价者为开发过程中的模型/规则检查，并非统一独立人工盲评。没有将未完成评分的材料包装成人工认可。

## 当前可以诚实宣称的表现

发布包整理后另进行了 8 次调用，使用本包实际 V2 正文、重新编写的表情目录，以及真实 whale_stickers 注入/解析方法；未经过完整群聊请求构造、读空气、视觉识别或 QQ 传输。所有输入为虚构场景，下一轮斗图使用本次实际生成的上一轮回复。原始输出完整保留在 [model-probe.json](model-probe.json)，没有筛选最佳回答。

| 本次场景 | 实际观察 | 本次评价（开发者模型复核，非人工盲评） |
|---|---|---|
| 刚说不想接哑铃话题，追问“为啥啊” | 回应不想聊哑铃的理由 | 承接方向相关；态度好不好是另一项判断 |
| 家里标18kg，体感不如另一只12kg重，尚未称重 | 提到称重核实，也断言“十几个人轮着用”“家里新买的”“棱角硬”等未给信息 | 信息保真不通过；不能因末尾建议称重就忽略前面的编造 |
| 工资进来，存款起身告辞 | 回复“挺懂事，就是不恋家”并选围观图 | 接续了离家逻辑；单例，不足以证明稳定幽默泛化 |
| 被夸可爱 | 选择否认可爱的表情，文字称“该问的我还是会问” | 图意相关，文字衔接较生硬，不记作自然度通过 |
| 寿来索要表情 | 选择 w066 token来 | 选图命中所测用途；没有检验实际视觉理解 |
| 私聊认真问字典两种取值方式，要求不配图 | 回答 KeyError/None、默认值和 __missing__ 差别，无图片标记 | 所测知识点与形式相关 |
| 两轮表情互动（两次调用） | 首轮 token来，次轮换图并明确“不陪你玩了” | 所测接续与收尾成立；最后一轮标记由测试明确给定，非读空气或随机轮数评测 |

因此本次没有给整个人格一个“自然程度总分”，也没有把 8 次接口成功等同于 8 个行为场景都正确。上述失败本轮只记录，不临时追加规则修到单个样本满意后再宣称通用改善。

已具备目标群和管理员私聊中的文字、语音转写、视觉描述、按需联网、摘要检索、称呼偏好及表情互动接入；关键状态路径有回归检查。能否接话仍受概率、冷却、疲劳、读空气和模型响应影响。当前初始概率 0.3 不等于群里每十条必回三条。

可以把它理解为“有具体性格、经过上下文和互动修复的机器人版本”。尚不能宣称稳定像真人、陌生梗泛化通过、长时间多人讨论不跑题、零幻觉或零误识别。V2 与原卡也没有经过同条件充分盲评，不能给出人格自然度提升百分比。

图像描述进入文本上下文，和主聊天模型直接看全部原图不同；延迟图片缓存不是永久相册。长期记忆会摘要、检索、归档，可能漏记或召回旧观点。称呼即时更正只覆盖明确命名句式，不是自动理解一切偏好更正的通用记忆系统。

收尾、发图与收图各有判断路径。模型可能说收尾话但未选图，图片缺失也可能退化为文字；“识别是小鲸鱼”不是版权审核。最终应在使用者自己的会话进行接收、响应、送达及持续观感检查。
