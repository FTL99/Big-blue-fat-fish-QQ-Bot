# 会话理解与按需检索

群聊消息保留消息来源、发送人、顺序、引用以及图文关联。当前图片尚无描述时保留其载体，不静默降为纯文字。

原参与判断入口现在同时执行中立会话理解，整理当前消息承接哪句、指代什么、交流意图及不确定信息。明确 @ 等触发仍可获得回复机会，正式表达沿用默认人格。

当前上下文足够时不检索。需要回溯时，在当前会话最多 200 条原始记录中按查询词项匹配，保留邻近原话，最多返回 8 条。长期记忆复用 LivingMemory 的会话、人格与白名单过滤，最多返回 5 条，并在同一轮请求内复用结果。

来源验证与最多一轮补充理解有助于减少误承接，但不能保证最终回复总能保持正确的人物关系。仍应结合实际群聊观察理解结果与生成结果是否一致。

相关回归使用虚构身份和受控记忆，不发送 QQ 消息。运行：`python -m unittest discover -s tests -p test_semantic_context.py -v`。
