## 通过的离线项目

- 217 个 Python 文件语法解析、JSON 可解析、66 张图片逐文件 SHA256 与目录记录一致。
- 在新空目录通过实际安装准备函数创建配置、插件、空收藏包；由 AstrBot 4.29.1 数据库 API 建库并写入导出的 V2，未复制生产数据库。
- 已有非空目录拒绝覆盖，非法群号拒绝写入；目标群与管理员私聊白名单按安装参数生成。

- 两张 PNG 参考图的导入文件名与图像/收图消费者一致；无参考图时收图默认关闭，不伪称已完成标准图对照。

重跑方式：先装 requirements.txt，在 PowerShell 运行 python tests/test_release.py。输入全部虚构；不调用模型，不启动 QQ、不发送消息。自动结果保存在 [offline-acceptance.json](offline-acceptance.json)。

测试使用已经安装的 Python/AstrBot 依赖，新建的是数据和配置目录。部分路由方法从实际源码提取执行，未冒充整个完整框架的端到端运行。
