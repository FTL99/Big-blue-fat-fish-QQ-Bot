# Bilibili reader attribution

The story-board timestamp normalization and tile-sampling approach in
`utils/bilibili_reader.py` is adapted from `dsh-bili-scroll`, commit
`4af98392ee078e02f50a7fd0bf0491033f4675ed`, including its vendored
`bilibili-mcp/mcp_server.py`. The surrounding HTTP and AstrBot integration
is written for this project. No DSH runtime or Bilibili write tools are included.

Upstream: https://github.com/c1overzz/dsh-bili-scroll
