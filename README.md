# 小鲸鱼 QQ 熟人群增强版

基于 [make-your-qq-ai-group-member](https://github.com/mtshang/make-your-qq-ai-group-member)、AstrBot 和相关插件整理的 Windows 机器人方案。目标是在熟人小群里，有一个保留傲娇、嘴硬和互损风格，同时能理解对话背景的小鲸鱼成员。相比原版，本版提高了她参与群聊、接话题的机会，让她更容易加入正在进行的讨论；这也意味着模型调用和 Token 消耗预计会增加，实际费用取决于群聊活跃度、上下文长度和回复内容。

这是社区整合与修改版，与 DeepSeek、腾讯及各上游项目没有官方隶属关系。适用 Python 3.12、AstrBot 4.29.1；本仓库不包含 QQ/NapCat 客户端、模型权重、真实聊天或账号凭据。

## 默认人设确实改了

本版默认启用 [DeepSeek 小鲸鱼·熟人群角色卡 V2](persona/whale-v2.md)，可与[原部署包人设](persona/upstream-default.md)逐字比较。生产配置核对的版本是 V2；此前讨论过的 V2.1 幽默实验方案没有当作默认人设发布。

| 调整项 | 原部署包倾向 | 本版默认方向 |
|---|---|---|
| 理解与表达的顺序 | 很强调去 AI 味、嘴硬、短句，也允许装傻和已读乱回 | 先理解当前消息承接谁、实际在问什么，再决定解释、调侃或不配合 |
| 回复长度 | 默认 1—10 字、一行短句 | 日常简短，认真讨论时允许把判断说完整 |
| 傲娇和互损 | 被怼通常优先顶回去 | 保留好胜和坏心眼，也允许认错、被反击和不必每次赢 |
| 关系与记忆 | 主要依赖提示及近期聊天 | 人格不凭空编造共同经历，配合实际提供的上下文、记忆与更正 |
| 参与群聊 | 原版参与策略 | 相比原版提高接话机会；有自然的参与机会时可主动发表观点，不要求每条都参与。回复增多通常也会增加模型调用和 Token 费用 |

这次修改没有把小鲸鱼改成客服。人格仍然允许犯懒、拒答、互损和偶尔跑题；改动目标是减少因没理解而乱回。V2 仍保留具体幽默示例，有模仿台词的风险；不是已经证明能独立接住所有陌生梗的人格。

## 相对原部署项目增加了什么

| 功能 | 来源与本版增量 |
|---|---|
| 上下文与追问 | 修改 group_chat_plus 的去重、顺序和回复上下文规则；历史出现过不代表问题已回答，多人对话结合引用与 @ 判断对象 |
| 图片上下文 | 原方案已经支持视觉模型。本版修复未触发回复的纯图片丢失问题，后续回复可补识别；提供标准参考图对照入口 |
| 表情和斗图 | 新增 whale_stickers：66 张固定图、按语境选图、同图续接、分开发送 @ 与表情衔接、随机 2—5 次收尾，认真问题退出斗图 |
| 收图 | 基于 meme_manager 增加小鲸鱼形象筛选，并隔离目标群与管理员私聊的收藏；收图不等于获得公开再分发授权 |
| 记忆 | 接入 LivingMemory 与本地 BGE 向量检索；新增即时称呼偏好保存，避免等待摘要后才更新称呼 |
| 语音和联网 | 启用上游 SenseVoice 本地转写及 AstrBot 搜索工具，并整理依赖与按需查询规则；这些能力来自上游 |
| 后台运行 | 复用并修改原管理器，增加隐藏启动、单实例操作和诊断；快捷方式不依赖“起始位置” |

当前增强功能限定一个配置的群，以及配置管理员与机器人的私聊。其他群/用户不自动获得相同接入范围。默认初始参与概率为 0.3，近期消息窗口 50 条；冷却、疲劳、读空气判断仍会影响是否回复。

## 实际表现与限制

这是经过本地修改和小样本验证的整合版。已有模型测试观察到：群聊轻松反应场景选图 9/10，管理员私聊 4/5；称呼更正场景 6 次均使用新称呼；群聊、私聊各完成一次三轮斗图测试。后续轮次使用当轮实际生成的回复，测试没有向 QQ 发送消息。

这些是不同阶段的功能检查，不能视作本次发布版在真实群中的成功率。用户此前实际遇到过追问接错、只抓关键词、旧称呼未及时更新、重复表情未续接及启动失败；本版包含针对这些问题的修复，但长期自然度仍需观察。也没有盲评证据证明 V2 一定比原卡更像真人。

本次导出包另做了 8 次虚构场景模型检查：能接“工资进来，存款就起身告辞”的新梗，选择 token来，认真问题不配图，并在两轮互动末尾说出不再陪玩的收尾话。但哑铃场景仍编造了“十几个人轮着用、握把磨得顺滑”等背景，未通过原始信息保真要求；不是全场景通过的版本。完整输出和范围见 [本次模型样本](docs/model-probe.json)。

图片识别、转写和搜索依赖配置与服务可用性；长期记忆是摘要和检索，不是逐字永久记忆。参考图尚未逐文件核清来源，本仓库先提供本地导入入口，未把两张网络原图标成自有素材公开发布。完整的测试范围、失败与局限见 [行为与证据](docs/BEHAVIOR.md)；本次发布整理的验收结果见 [验收记录](docs/ACCEPTANCE.md)。

## 安装与使用

按 [Windows 安装说明](docs/INSTALL.md)操作。安装器只接受全新空目录，不覆盖既有机器人；不会自动启动服务或向 QQ 发消息。模型接口默认配置来自这次部署，接口权限和视觉能力需自行核实；可在 AstrBot 面板替换文本、视觉模型。

安装器通过环境变量或隐藏输入读取 API Key，不把 Key 写入源码或终端。生成的运行配置、面板凭据、聊天及记忆只保存在独立安装目录。不要把运行目录整体提交到 GitHub。
